# Пошаговая инструкция: запуск сайта на SpaceWeb (Тариф «Взлет»)

Данная инструкция содержит полный порядок действий для размещения сайта ВРОО «ОФБ» на виртуальном хостинге **SpaceWeb (sweb.ru)** по тарифу **«Взлет»**.

---

## Ключевые параметры тарифа «Взлет»
* **Стоимость:** 1 428 ₽ за 1-й год (119 ₽/мес), продление со 2-го года — 1 788 ₽/год (~149 ₽/мес).
* **Домен .ru:** 189 ₽ регистрация, 285 ₽ продление.
* **Итоговый бюджет:** ~1 617 ₽ в первый год, ~2 073 ₽ со второго года (~173 ₽/мес).
* **Диск:** 5 ГБ SSD (хватит для сайта и архивов документов/протоколов).
* **Документооборот:** безналичный расчет по счету для юрлиц/НКО, УПД через Диадок / СБИС.

---

## Шаг 1. Регистрация на SpaceWeb и заказ тарифа

1. Перейдите на [sweb.ru](https://sweb.ru/) → **Хостинг** → выберите тариф **«Взлет»** (период оплаты: 1 год для получения минимальной цены).
2. При регистрации выберите тип плательщика: **«Юридическое лицо»** (ВРОО «ОФБ»).
3. Введите реквизиты организации (ИНН, ОГРН, юридический адрес).
4. Выберите или зарегистрируйте домен в зоне `.ru`: **`basket34.ru`**.
5. Сформируйте счёт на безналичную оплату.
6. В разделе биллинга укажите идентификатор вашей организации в **Контур.Диадок** или **СБИС**, чтобы закрывающие документы (УПД) приходили автоматически без бумажной волокиты.

---

## Шаг 2. Активация постоянного SSH/SFTP доступа (ВАЖНО для автодеплоя)

В SpaceWeb терминальный доступ SSH по умолчанию включается временно (на 24 часа). Чтобы автоматическая выгрузка сайта из GitHub Actions раннеров работала постоянно и не отключалась, нужно один раз отправить тикет в поддержку:

1. В панели управления SpaceWeb перейдите в раздел **«Поддержка»** → **«Создать обращение»**.
2. Скопируйте и отправьте следующий текст:

> **Тема:** Постоянный бессрочный доступ по SSH/SFTP для CI/CD
>
> **Сообщение:**
> Здравствуйте!
> На нашем аккаунте разворачивается сайт спортивной общественной организации (ВРОО «ОФБ»). Сборка и публикация осуществляются автоматически через раннеры GitHub Actions по протоколу SFTP (порт 22).
> 
> Просим закрепить постоянный бессрочный доступ по SSH/SFTP для основного пользователя без автоматического отключения через 24 часа.
> 
> Заранее спасибо!

Поддержка SpaceWeb обрабатывает такие заявки в течение 10–20 минут.

---

## Шаг 3. Настройка версии PHP и SSL-сертификата

1. **Версия PHP:**
   * В панели SpaceWeb откройте раздел **«Сайты»**.
   * Нажмите на шестерёнку рядом с вашим доменом.
   * В графе «Версия PHP» выберите **PHP 8.2** или **PHP 8.3**.
2. **Бесплатный SSL-сертификат (HTTPS):**
   * В разделе **«Сайты»** перейдите во вкладку **«SSL-сертификаты»**.
   * Выберите ваш домен и нажмите **«Заказать бесплатный сертификат Let's Encrypt»**.
   * Включите автопродление. Через 10–15 минут сайт будет защищён по HTTPS.

---

## Шаг 4. Регистрация GitHub OAuth App для админки

Чтобы сотрудники федерации могли безопасно входить в панель управления `/admin/`:
1. В аккаунте владельца репозитория перейдите в [github.com/settings/developers](https://github.com/settings/developers) → **OAuth Apps** → **New OAuth App**.
2. Заполните:
   * **Application name:** `Сайт ВРОО «ОФБ»`
   * **Homepage URL:** `https://ВАШ-ДОМЕН`
   * **Authorization callback URL:** строго `https://ВАШ-ДОМЕН/oauth/callback.php`
3. Нажмите **Register application**.
4. Скопируйте **Client ID**.
5. Нажмите **Generate a new client secret** и скопируйте сгенерированный ключ (**Client Secret**).

---

## Шаг 5. Создание файла с ключами `secret.php` на хостинге

1. В панели SpaceWeb откройте **«Файловый менеджер»** (или подключитесь по SFTP через FileZilla).
2. Перейдите в каталог сайта: `domains/ВАШ-ДОМЕН/public_html/oauth/` (или `public_html/oauth/`).
3. Скопируйте файл `secret.sample.php` в `secret.php`.
4. Откройте `secret.php` в редакторе хостинга и укажите:
   ```php
   <?php
   declare(strict_types=1);

   define('GITHUB_CLIENT_ID', 'ВАШ_CLIENT_ID');
   define('GITHUB_CLIENT_SECRET', 'ВАШ_CLIENT_SECRET');
   define('OAUTH_STATE_SECRET', 'любая-длинная-случайная-строка-символов-для-безопасности');
   ```
5. Сохраните файл. Он надёжно защищён правилами файла `.htaccess` от просмотра посторонними.

---

## Шаг 6. Настройка секретов в GitHub Actions для автодеплоя

В вашем репозитории на GitHub:
1. Откройте **Settings → Secrets and variables → Actions → New repository secret**.
2. Создайте следующие переменные (значения берутся из письма с данными доступа SpaceWeb):
   * `HOSTING_SERVER`: адрес сервера SpaceWeb (например, `ваш-логин.nichost.ru` или `sweb.ru` / IP-адрес сервера из панели);
   * `HOSTING_USERNAME`: ваш логин на хостинге SpaceWeb;
   * `HOSTING_PASSWORD`: ваш пароль доступа к хостингу;
   * `HOSTING_PORT`: `22` (SFTP);
   * `HOSTING_TARGET_DIR`: целевая папка (обычно `domains/ВАШ-ДОМЕН/public_html/` или `public_html/`).

---

## Шаг 7. Проверка работы

1. Сделайте любой коммит в репозиторий или запустите workflow **«Деплой на российский хостинг (SFTP)»** вручную на вкладке **Actions** в GitHub.
2. После успешной выгрузки:
   * Откройте сайт: `https://ВАШ-ДОМЕН/` — проверьте отображение страниц;
   * Откройте панель: `https://ВАШ-ДОМЕН/admin/` — нажмите кнопку **«Login with GitHub»**;
   * Откроется окно входа GitHub, запросит подтверждение, закроется и откроет полноценную панель редактирования сайта.
