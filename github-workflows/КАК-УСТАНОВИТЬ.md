# Файлы GitHub Actions

Два файла в этой папке нужно положить в проект по пути `.github/workflows/`:

```
.github/workflows/deploy.yml
.github/workflows/sync-news.yml
```

Папку `github-workflows` после этого можно удалить.

**Проще всего сделать это прямо на GitHub:**
Add file → Create new file → в поле имени ввести
`.github/workflows/deploy.yml` → вставить содержимое → Commit.
Затем то же самое для `sync-news.yml`.

- `deploy.yml` — собирает сайт и публикует его на GitHub Pages
  (при каждом коммите в `main` и вручную).
- `sync-news.yml` — каждые 2 часа забирает новости из группы ВКонтакте,
  обновляет `data/news.json` и запускает пересборку сайта.
  Требует секрет `VK_API_TOKEN` (см. README, раздел «Настройка VK API»).
