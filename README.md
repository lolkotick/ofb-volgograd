# Сайт ВРОО «Областная федерация баскетбола»

Официальный сайт Волгоградской региональной общественной организации
«Областная федерация баскетбола» (ВРОО «ОФБ»).
Новости, календарь матчей, документы и направления работы федерации.

- **Технологии:** Astro (статическая генерация), обычные HTML/CSS/JS на выходе — сервер не нужен
- **Хостинг:** GitHub Pages (бесплатно)
- **Новости:** автоматически подтягиваются из группы [vk.com/vrooofb](https://vk.com/vrooofb) через VK API
- **Календарь матчей:** ведётся вручную в файле `data/matches.json`
- **Адрес сайта:** https://lolkotick.github.io/ofb-volgograd/

> Если вы администратор федерации и вам нужно просто поменять текст, добавить матч
> или документ — откройте **[ИНСТРУКЦИЯ-ДЛЯ-АДМИНИСТРАТОРА.md](ИНСТРУКЦИЯ-ДЛЯ-АДМИНИСТРАТОРА.md)**.
> Этот файл — техническая документация.

## 2. Запуск на своём компьютере

Нужен [Node.js](https://nodejs.org/) версии 20 или новее — скачайте версию **LTS**
и установите со всеми настройками по умолчанию. Проверить, что всё встало:
откройте терминал и наберите `node -v` — должно ответить `v20.…` или новее.

Дальше откройте терминал **в папке проекта**. На Windows проще всего так:
зайдите в папку проекта в проводнике, щёлкните по адресной строке,
наберите `powershell` и нажмите Enter.

```bash
npm install         # установить зависимости (один раз, займёт минуту)
npm run dev         # локальный просмотр: http://localhost:4321
npm run build       # собрать статику в папку dist/
npm run preview     # посмотреть собранную версию
```

После `npm run dev` откройте в браузере адрес, который покажет терминал
(обычно http://localhost:4321). Страницы обновляются сами при правке файлов.
Остановить сервер — `Ctrl + C` в терминале.

Чтобы посмотреть, как выглядит лента новостей до подключения VK API,
запустите с демонстрационными новостями.

Windows, PowerShell:

```powershell
$env:USE_SAMPLE_NEWS = "1"; npm run dev
```

Windows, командная строка (cmd):

```bat
set USE_SAMPLE_NEWS=1 && npm run dev
```

macOS / Linux:

```bash
USE_SAMPLE_NEWS=1 npm run dev
```

Демо-новости живут в `data/news.sample.json` и **никогда не попадают на боевой сайт**.

## 3. Публикация на GitHub Pages

> **Сайт уже опубликован:** https://lolkotick.github.io/ofb-volgograd/
> Репозиторий: https://github.com/lolkotick/ofb-volgograd
> Workflow-файлы лежат в `.github/workflows/`, GitHub Pages включён.
> Раздел ниже нужен, только если сайт придётся разворачивать заново или переносить
> в другой аккаунт.

1. Создайте репозиторий на GitHub (например `ofb-volgograd`) и загрузите в него этот проект,
   ветка **main**. Файлы `.github/workflows/deploy.yml` и `.github/workflows/sync-news.yml`
   должны попасть в репозиторий — без них не работает ни публикация, ни обновление новостей.
2. В репозитории откройте **Settings → Pages** и в поле *Source* выберите **GitHub Actions**.
3. Сделайте любой коммит в `main` — сработает workflow «Сборка и публикация сайта».
4. Через 1–2 минуты сайт будет доступен по адресу
   `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Адрес сайта подставляется в сборку автоматически из имени репозитория — ничего править не нужно.

### Свой домен (когда появится)

1. **Settings → Pages → Custom domain** — укажите домен, GitHub создаст файл `CNAME`.
2. Добавьте переменные репозитория (**Settings → Secrets and variables → Actions → Variables**):
   - `SITE_URL` = `https://ваш-домен.ru`
   - `SITE_BASE` = `/`
3. У регистратора домена пропишите DNS-записи по
   [инструкции GitHub](https://docs.github.com/pages/configuring-a-custom-domain-for-your-github-pages-site).

## 4. Настройка VK API (автообновление новостей)

### Шаг 1. Получить ключ доступа сообщества

1. Зайдите в группу федерации во ВКонтакте под аккаунтом администратора.
2. **Управление сообществом → Настройки → Работа с API → Ключи доступа**.
3. Нажмите **Создать ключ**, отметьте право доступа **«Стена»** (`wall`).
4. Скопируйте появившийся длинный ключ.

> Ключ — это пароль. Его нельзя вставлять в код, отправлять в чат или коммитить в репозиторий.

### Шаг 2. Положить ключ в GitHub Secrets

1. Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**.
2. Имя: `VK_API_TOKEN`, значение: скопированный ключ. Сохранить.

Если короткий адрес группы когда-нибудь изменится, добавьте туда же **переменную**
(вкладка *Variables*) `VK_GROUP_DOMAIN` со значением нового адреса без `vk.com/`.

### Шаг 3. Проверить синхронизацию

Репозиторий → **Actions → «Новости из ВКонтакте» → Run workflow**.
Через минуту в `data/news.json` появятся записи, а сайт пересоберётся сам.

Дальше синхронизация идёт по расписанию — **каждые 2 часа**
(изменить: строка `cron` в `.github/workflows/sync-news.yml`, время в UTC).

### Что делает скрипт

`scripts/sync-vk-news.mjs`:

1. вызывает `wall.get` для группы с ключом из `VK_API_TOKEN`;
2. отбрасывает рекламные и служебные записи;
3. вытаскивает текст, дату, обложку и фотографии;
4. перезаписывает `data/news.json`.

Файл `data/news.json` **редактировать вручную не нужно** — он перезаписывается при каждом запуске.

### Если что-то не работает

| Сообщение в логе | Что делать |
|---|---|
| `VK API ошибка 5` | Ключ отозван или неверный — создайте новый и обновите secret |
| `VK API ошибка 15` | У ключа нет права «Стена» либо стена закрыта |
| `VK API ошибка 100` | Неверный короткий адрес группы (`VK_GROUP_DOMAIN`) |
| `VK API ошибка 29` | Слишком частые запросы — увеличьте интервал в cron |

## 5. Структура проекта

```
data/                     ← ВСЕ ДАННЫЕ САЙТА (правит администратор)
  site.json               общие сведения и контакты федерации
  leadership.json         карточки руководства
  matches.json            календарь матчей
  documents.json          список документов
  news.json               ← перезаписывается автоматически, не трогать
  news.sample.json        демо-новости только для локального просмотра
  sections.json           направления работы: меню и содержание страниц

public/                   файлы, которые попадают на сайт как есть
  logo/                   логотип в разных вариантах
  documents/              сюда класть PDF-файлы документов
  leadership/             сюда класть фотографии руководства
  favicon.*, og-image.png иконки и картинка для соцсетей

src/
  layouts/BaseLayout.astro   общий каркас страницы, метатеги, SEO
  components/                шапка, подвал, карточки новостей и матчей
  pages/                     страницы сайта (файл = адрес)
  lib/data.js                чтение данных из /data и форматирование
  lib/nav.js                 меню, читает список направлений из data/sections.json
  styles/global.css          вся вёрстка и палитра

scripts/sync-vk-news.mjs  синхронизация новостей с ВКонтакте
.github/workflows/        автоматическая сборка, публикация и синхронизация
```

## 6. Дизайн

- Палитра: оранжевый `#F5761A` / `#FF7A00`, фон `#111111`–`#1A1A1A`, текст белый.
  Все цвета заданы переменными в начале `src/styles/global.css` — меняются в одном месте.
- Шрифт: Inter (кириллица), подключается с Google Fonts.
- Вёрстка адаптивная, основной расчёт — на телефоны.
- Доступность: контраст текста не ниже AA, видимый фокус на всех интерактивных элементах,
  ссылка «Перейти к содержанию», alt-тексты у всех изображений, таблица календаря
  прокручивается по горизонтали и не ломает страницу.

## 7. Второй этап: что заложено на будущее

- **Автоматический источник календаря.** Сейчас матчи — ручной JSON. Точка подключения
  внешнего фида (например РФБ) отмечена комментарием в `src/lib/data.js`: достаточно
  написать скрипт, который приводит данные фида к той же структуре и пишет их
  в `data/matches.json`. Страницы календаря менять не придётся.
- **Наполнение восьми разделов.** Механика готова: содержание берётся из
  `data/sections.json`, страница собирается из блоков (текст, шаги, карточки,
  вопрос-ответ, контакт). У детского, любительского и судейского разделов каркас
  уже собран — осталось заменить подсказки на реальные данные и поставить
  `published: true`. Пока флаг `false`, раздел закрыт заглушкой и не индексируется.
- **Медиагалерея и трансляции** — механика встраивания VK Видео уже работает на страницах матчей.
