# Промпт для поиска хостинга

Скопируйте текст ниже целиком и отправьте другому ИИ с доступом в интернет.

---

Ты подбираешь хостинг для сайта региональной спортивной федерации. Нужен
конкретный ответ с ценами и ссылками, а не общие рассуждения. Проверяй факты
на сайтах провайдеров, а не по памяти: тарифы и условия меняются. Если чего-то
не нашёл или не уверен — так и напиши, не додумывай.

## Что за проект

Статический сайт: набор готовых HTML-файлов, собранных генератором Astro.
Базы данных нет, серверной логики почти нет. Сейчас сайт лежит на GitHub Pages,
переезжаем из-за нестабильной доступности зарубежных сервисов из России.

Аудитория — жители Волгоградской области. Все посетители заходят из России.

Как устроена публикация: сборка происходит на серверах GitHub (GitHub Actions),
готовые файлы автоматически заливаются на хостинг по FTP или SFTP при каждом
изменении. Вручную ничего не загружается.

Размер: сейчас около 15 МБ, с запасом на фотографии и PDF-документы — до 2 ГБ.
Посещаемость низкая: региональная федерация, счёт идёт на сотни визитов в месяц.

## Обязательные требования

1. **Российский хостинг**, серверы в России, аккредитованный регистратор
   или провайдер с российским юрлицом.
2. **Доступ по FTP или SFTP** для автоматической загрузки файлов из GitHub Actions.
3. **PHP** — нужен для одного небольшого скрипта авторизации (около 60 строк,
   без базы данных). Версия 8.0 и новее.
4. **Бесплатный SSL-сертификат** с автопродлением (Let's Encrypt или аналог).
5. **Цена до 500 ₽ в месяц** при оплате за год.

## Желательно

- Возможность оплаты **по безналичному расчёту с закрывающими документами** —
  сайт ведёт общественная организация, оплата может идти от юрлица.
- Регистрация домена `.ru` у того же провайдера, чтобы не разносить по разным
  личным кабинетам. Укажи цену первого года и продления — они часто различаются.
- Резервное копирование на стороне провайдера.
- Панель управления на русском языке.
- Поддержка, отвечающая на русском.

## Что проверить особенно внимательно

Это тонкие места, на которых обычно спотыкаются. По каждому дай прямой ответ.

1. **Не блокирует ли хостинг подключения с зарубежных IP-адресов.**
   Серверы GitHub Actions находятся за пределами России. Если провайдер
   ограничивает FTP/SFTP по географии или требует белый список адресов,
   автоматическая публикация работать не будет. Диапазоны адресов GitHub
   меняются, статический белый список не подойдёт.
2. **Есть ли ограничение на число FTP-подключений или частоту загрузок**,
   которое может сработать при заливке нескольких сотен файлов подряд.
3. **Даёт ли тариф доступ по SFTP или только по обычному FTP.** SFTP
   предпочтительнее: пароль не идёт по сети открытым текстом.
4. **Есть ли автопродление SSL** и не требует ли оно ручных действий раз в 90 дней.
5. **Что происходит при неуплате**: сразу отключение, есть ли льготный период,
   удаляются ли данные и через какой срок. Для общественной организации,
   где оплата может задержаться, это существенно.
6. **Реальная цена на второй год.** Первый год часто со скидкой; сравнивай
   по цене продления, а не по цене входа.

## Что не нужно и не предлагай

- VPS и выделенные серверы: администрировать их некому.
- Тарифы под WordPress, Bitrix и другие CMS: сайт статический.
- Зарубежные провайдеры и всё, что работает через Cloudflare как обязательный
  слой: от этого мы как раз уходим.
- Конструкторы сайтов: сайт уже написан, его нужно просто разместить.

## Формат ответа

1. **Таблица сравнения** 4–6 подходящих тарифов у разных провайдеров:
   провайдер, тариф, цена в месяц при годовой оплате, цена продления, место
   на диске, версия PHP, FTP/SFTP, SSL, резервные копии, оплата от юрлица.
2. **Рекомендация** — один основной вариант и один запасной, с объяснением,
   почему именно они, и чем один хуже другого.
3. **По каждому пункту раздела «что проверить особенно внимательно»** — что
   удалось выяснить, со ссылкой на источник. Если ответа на сайте провайдера
   нет, так и напиши: «не указано, нужно спросить в поддержке».
4. **Список вопросов в поддержку** перед покупкой — то, что нельзя выяснить
   из документации.
5. **Дата**, на которую актуальны цены, и ссылки на страницы с тарифами.
