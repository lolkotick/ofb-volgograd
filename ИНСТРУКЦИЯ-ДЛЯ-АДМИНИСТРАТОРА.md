# Как вести сайт федерации

Всё содержание сайта правится через панель управления в браузере.
Программировать и разбираться в файлах не нужно.

**Адрес панели:** https://lolkotick.github.io/ofb-volgograd/admin/

Вход — через аккаунт GitHub. Если у вас его ещё нет или нет доступа,
попросите администратора репозитория пригласить вас (см. файл
`ВХОД-В-ПАНЕЛЬ-НАСТРОЙКА.md`, раздел «Как добавить сотрудника»).

---

## Главное правило: сайт не показывает незаполненное

На сайте федерации не должно быть ни одной выдуманной строчки — посетитель
принимает написанное за факт и действует по нему: приходит на матч, звонит
по телефону, ждёт документ.

Поэтому сайт устроен так:

- **Незаполненное поле не выводится.** Пустой телефон или адрес просто не
  появится на странице, вместо него посетитель увидит честную заглушку.
- **Документ виден, только когда приложен файл.** Название без файла — это
  обещание, которого сайт не выполнит.
- **Карточка руководителя появляется, когда вписано настоящее ФИО.**
- **Раздел открывается только переключателем «Опубликован».**
- **Календарь пустой, пока вы не внесли матчи.**

Не включайте раздел, пока в нём остались подсказки вида «Укажите текст» —
они попадут на живой сайт и будут видны посетителям.

## Как работать с панелью

1. Откройте адрес панели и войдите через GitHub.
2. Слева выберите раздел: календарь, о федерации, документы или направления.
3. Внесите изменения. Под каждым полем есть подсказка, что туда писать.
4. Нажмите **Опубликовать** (кнопка сверху).
5. Через 1–2 минуты изменения появятся на сайте.

Изменения сохраняются в историю: любую правку видно и можно откатить.
Ничего необратимого в панели сделать нельзя.

## Новости

**Ничего делать не нужно.** Новости берутся из сообщества
[vk.com/vrooofb](https://vk.com/vrooofb) автоматически, каждые два часа.
Опубликовали пост — он сам появится на сайте.

Заголовком новости на сайте становится первая строка поста, поэтому
начинайте посты с короткой ясной фразы, а подробности пишите дальше.

В ленте держатся 30 последних записей.

## Календарь матчей

Раздел **«Календарь матчей» → «Расписание матчей»**.

Кнопка **«Добавить матч»** создаёт пустую карточку. Поля:

| Поле | Что писать |
|---|---|
| Дата | Выбирается в календарике |
| Время начала | Например 17:00. Пусто — время неизвестно |
| Лига или категория | Чемпионат области, первенство среди юношей и т.д. |
| Команда 1, Команда 2 | Названия команд |
| Место проведения | Спортзал или арена |
| Город | Город проведения |
| Домашняя игра | Включено — игра в области, выключено — выезд |
| Статус | «Предстоит» или «Сыгран» |
| Счёт | Заполняется после игры |
| Трансляция во ВКонтакте | Ссылка на эфир, если он есть |
| Код матча | Латиницей, попадает в адрес страницы матча |

**После матча:** поменяйте статус на «Сыгран» и впишите счёт.

Матчи можно перетаскивать мышкой за полоски справа, чтобы менять порядок,
и удалять крестиком.

### Трансляция матча

Сайт не ведёт собственный эфир — он показывает уже существующую трансляцию
клуба или арены во ВКонтакте.

1. Откройте трансляцию в VK Видео.
2. **Поделиться → Код для вставки**.
3. Скопируйте оттуда адрес вида
   `https://vk.com/video_ext.php?oid=-123456&id=456239017&hash=abc123`.
4. Вставьте в поле «Трансляция во ВКонтакте».

Подойдёт и обычная ссылка вида `https://vk.com/video-123456_456239017`.
Пустое поле — блок с видео на странице матча не показывается.

## Руководство федерации

Раздел **«О федерации» → «Руководство»**.

По каждому человеку: ФИО, должность, фотография, почта и телефон
(последние два необязательны). Порядок карточек в панели = порядок на сайте.

Фотография загружается прямо в панели кнопкой выбора файла.
Портрет, желательно не меньше 400×400 точек.

## Контакты и общие сведения

Раздел **«О федерации» → «Контакты и общие сведения»**.

Адрес, телефон, почта, часы работы, миссия федерации, ссылка на сообщество.
Здесь же реквизиты — ОГРН, ИНН, юридический адрес: пока они пустые, блок
реквизитов в подвале сайта не показывается.

Как только заполните электронную почту, на странице контактов включится
форма обращения: посетитель заполняет поля, письмо уходит вам.

## Документы

Раздел **«Документы» → «Список документов»**.

Кнопка **«Добавить документ»**, дальше название, категория, описание и сам
файл — загружается прямо в панели.

Документы группируются на странице по категории: одинаковое название
категории — один блок.

Пока файл не приложен, документ на сайте не показывается.

## Направления работы

Раздел **«Направления работы» → «Восемь направлений»**.

У каждого направления есть переключатель **«Опубликован»**. Пока он выключен,
посетитель видит страницу «Раздел готовится».

Страница собирается из блоков — кнопка **«Добавить блок»** предлагает пять
типов:

| Тип | Для чего |
|---|---|
| Текст | Заголовок и абзацы |
| Шаги | Порядок действий: как заявиться, как записаться |
| Карточки | Плитки: секции, турниры, категории |
| Вопросы и ответы | Раскрывающийся список вопросов |
| Контакт ответственного | Карточка сотрудника, отвечающего за направление |

Блоки идут на странице сверху вниз в том порядке, в каком стоят в панели.
Лишние удаляются крестиком, порядок меняется перетаскиванием.

У трёх направлений — детского, любительского и судейского — каркас уже
собран: заголовки блоков, шаги и вопросы подобраны. Осталось заменить
подсказки «Укажите текст» на реальные данные.

## Если что-то пошло не так

Все изменения хранятся в истории. Чтобы вернуть как было, напишите
администратору сайта — любую правку можно откатить.

Панель не даёт сломать сайт: если поле заполнено неверно, сборка не пройдёт
и на сайте останется прежняя версия.
