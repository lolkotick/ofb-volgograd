# Как редактировать сайт федерации

Инструкция для сотрудника федерации. Программировать не нужно —
всё содержание сайта лежит в четырёх файлах в папке `data`.

Любое изменение делается так:

1. Открыть нужный файл на GitHub → нажать карандаш **Edit**.
2. Внести правку.
3. Нажать **Commit changes**.
4. Через 1–2 минуты сайт обновится сам.

> Файлы в формате JSON. Главные правила: текст всегда в `"кавычках"`,
> между записями стоит запятая, после последней записи запятой нет.
> Если сайт после правки не собрался — откройте вкладку **Actions**,
> красный крестик покажет, в какой строке ошибка.

## Новости

**Ничего делать не нужно.** Новости берутся из группы
[vk.com/vrooofb](https://vk.com/vrooofb) автоматически, каждые 2 часа.
Опубликовали пост во ВКонтакте — он сам появится на сайте.

Чтобы обновить ленту немедленно: вкладка **Actions → «Новости из ВКонтакте» → Run workflow**.

Заголовком новости на сайте становится первая строка поста — поэтому
начинайте посты с короткой ясной фразы, а подробности пишите дальше.

## Календарь матчей — `data/matches.json`

Каждый матч — один блок в списке `matches`:

```json
{
  "id": "2026-09-13-volgograd-volzhsky",
  "date": "2026-09-13",
  "time": "17:00",
  "league": "Чемпионат Волгоградской области, мужчины",
  "team1": "Волгоград",
  "team2": "Волжский",
  "venue": "СК «Динамо»",
  "city": "Волгоград",
  "home": true,
  "status": "upcoming",
  "score": "",
  "broadcast_url": "",
  "note": "1-й тур"
}
```

| Поле | Что писать |
|---|---|
| `id` | Уникальный код латиницей, попадает в адрес страницы. Удобно: дата-команда-команда |
| `date` | Дата в формате `ГГГГ-ММ-ДД` |
| `time` | Время начала `ЧЧ:ММ`. Неизвестно — оставьте `""` |
| `league` | Лига или категория соревнования |
| `team1`, `team2` | Названия команд |
| `venue` | Спортзал или арена |
| `city` | Город проведения |
| `home` | `true` — игра в Волгоградской области, `false` — выезд команды региона |
| `status` | `"upcoming"` — предстоит, `"finished"` — сыгран |
| `score` | Счёт `"81:69"`. Заполняется только для сыгранных матчей |
| `broadcast_url` | Ссылка на трансляцию во ВКонтакте (см. ниже). Нет трансляции — `""` |
| `note` | Короткий комментарий: тур, стадия. Можно оставить `""` |

**После матча:** поменяйте `"status"` на `"finished"` и впишите `"score"`.

### Как добавить трансляцию матча

Сайт не ведёт собственный эфир — он показывает уже существующую трансляцию
клуба или арены во ВКонтакте.

1. Откройте трансляцию (или запись) в VK Видео.
2. Нажмите **Поделиться → Код для вставки**.
3. Скопируйте оттуда адрес вида
   `https://vk.com/video_ext.php?oid=-123456&id=456239017&hash=abc123`.
4. Вставьте его в поле `"broadcast_url"` нужного матча.

Подойдёт и обычная ссылка вида `https://vk.com/video-123456_456239017` —
сайт сам соберёт из неё плеер.

Если поле пустое, блок с видео на странице матча просто не показывается.

## Руководство федерации — `data/leadership.json`

```json
{
  "id": "chairman",
  "name": "Иванов Иван Иванович",
  "role": "Председатель",
  "photo": "/leadership/ivanov.jpg",
  "email": "ivanov@example.ru",
  "phone": "+7 900 000-00-00",
  "note": ""
}
```

- Порядок карточек на сайте = порядок в файле.
- Фотографию положите в папку `public/leadership/` и укажите путь как в примере.
- Если `photo` оставить пустым (`""`), покажется аккуратная заглушка с инициалами.
- `email`, `phone`, `note` необязательны — пустые поля просто не выводятся.
- Добавить ещё человека: скопируйте блок целиком, поставьте запятую между блоками
  и поменяйте `id` на уникальный.

## Документы — `data/documents.json`

1. Загрузите PDF-файл в папку `public/documents/`
   (на GitHub: открыть папку → **Add file → Upload files**).
2. В `data/documents.json` заполните карточку:

```json
{
  "id": "ustav",
  "title": "Устав ВРОО «Областная федерация баскетбола»",
  "category": "Учредительные документы",
  "description": "Основной учредительный документ организации.",
  "file": "/documents/ustav.pdf",
  "size": "1,2 МБ",
  "date": "2024-03-15"
}
```

Пока `"file"` пустое, карточка показывается с пометкой «Файл готовится к публикации» —
битой ссылки на сайте не появится.

Документы группируются на странице по полю `category`: одинаковое название категории —
один блок.

## Контакты и общие тексты — `data/site.json`

Здесь адрес, телефон, электронная почта, часы работы, миссия федерации и ссылка на ВКонтакте.
Замените плейсхолдеры вида `указать адрес` и `+7 (___) ___-__-__` на реальные данные.

В блоке `requisites` можно указать ОГРН, ИНН и юридический адрес — они появятся
в подвале сайта. Пока поля пустые, блок реквизитов не показывается.

## Направления работы — `data/sections.json`

Восемь разделов (аккредитация, судейский корпус, любительский, студенческий,
детский, интерактивный, фиджитал и «тихий» баскетбол) есть в меню всегда.
Пока раздел не заполнен, посетитель видит страницу «Раздел готовится».

Весь раздел описывается одним блоком в файле `data/sections.json`:

```json
{
  "slug": "youth",
  "title": "Детский баскетбол",
  "short": "Детский",
  "description": "Короткое описание — показывается под заголовком страницы",
  "published": false,
  "blocks": [ ... ]
}
```

**`published`** — главный переключатель. Пока стоит `false`, раздел закрыт заглушкой.
Поставьте `true`, когда содержание готово, — страница откроется публично.

> Не включайте раздел, пока в нём остались подсказки вида «Укажите текст» —
> они попадут на живой сайт и будут видны посетителям.

### Из чего собирается страница

Список `blocks` — это содержание страницы сверху вниз. Лишние блоки удаляйте
целиком, нужные копируйте. Доступно пять типов:

| Тип | Для чего | Поля |
|---|---|---|
| `text` | Обычный текст | `title`, `body` — список абзацев |
| `steps` | Порядок действий по шагам | `title`, `items` с `title` и `text` |
| `cards` | Плитки: секции, турниры, категории | `title`, `items` с `title`, `subtitle`, `text`, `contact` |
| `faq` | Вопрос — ответ | `title`, `items` с `q` и `a` |
| `contact` | Карточка ответственного | `title`, `name`, `role`, `email`, `phone` |

Поле `note` у любого блока — подпись под заголовком. Сейчас там подсказки для вас;
перед публикацией удалите их или замените пояснением для посетителей.
Пустые `email` и `phone` на сайте не показываются.

### Что уже готово

У трёх разделов — **детский**, **любительский** и **судейский корпус** — каркас уже
собран: заголовки блоков, шаги, вопросы. Осталось заменить подсказки на реальные
данные и поставить `published: true`.

У остальных пяти список `blocks` пустой — структуру для них можно скопировать
у любого из трёх готовых.

## Что делать, если сайт сломался

1. Вкладка **Actions** в репозитории — там видно, какая сборка упала.
2. Откройте красную запись, разверните шаг с ошибкой — обычно это забытая запятая
   или лишняя кавычка в JSON.
3. Быстрый откат: **Commits** → найти последний рабочий коммит → **Revert**.

Проверить JSON перед сохранением можно на любом онлайн-валидаторе,
вставив туда содержимое файла.
